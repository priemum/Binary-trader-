# نظام تحليل الشارت وتنبؤ الشمعة القادمة

هذا المشروع هو نظام ويب للتحليل الفني للشموع اليابانية وتنبؤ الشمعة القادمة.

## المميزات

- تحليل الشارتات المالية
- تنبؤ الشمعة القادمة
- التعرف على أنماط الشموع اليابانية
- تحليلات متقدمة باستخدام الذكاء الاصطناعي

## المتطلبات الأساسية

- Node.js
- npm
- OpenCV (اختياري)

## التثبيت

1. تثبيت التبعيات:
```bash
npm install
```

2. تشغيل الخادم:
```bash
npm start
```

## الاستخدام

قم بزيارة `http://localhost:3000` بعد تشغيل الخادم

## التكنولوجيا المستخدمة

- Express
